I'm a cybersecurity professional with hands-on expertise in **penetration testing**, **vulnerability assessment**, and **offensive security**. Currently pursuing my **ICDFA (International Cybersecurity Defense Forensics Analyst)** certification through practical internship experience.

**My Philosophy:** I learn by doing. Every lab represents a real vulnerability I've exploited, a system I've compromised, and a lesson I've internalized. I'm focused on understanding *how* attacks work from first principles and documenting findings professionally.
